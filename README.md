# Мой курс

Нативное десктопное приложение для Mac на SwiftUI. Цели, числовой прогресс, задачи со сроками и перенос списка в Apple Заметки. Работает без браузера, сервера и подключения к интернету.

## Запуск

Откройте `Build/MyDashboard.app` двойным щелчком. Можно перенести приложение в папку «Программы» и закрепить в Dock. Если сборки ещё нет, откройте `Open MyDashboard.command`: он соберёт и запустит приложение.

Минимальная версия — macOS 14. Сборка создаётся для архитектуры Mac, на котором выполняется команда. Готовый локальный пакет подписан ad-hoc; для распространения через интернет потребуются Developer ID и нотарификация.

## Возможности

- Создание и редактирование целей по сферам жизни.
- Прогресс по числовому показателю или доле выполненных задач.
- Задачи, связанные с целями, сроки, приоритеты, поиск и фильтры.
- Обзор общего прогресса и выполненных задач за последние семь дней.
- Системное меню «Поделиться», копирование и TXT для Apple Заметок.
- JSON-копии, проверка перед восстановлением и защита повреждённого файла.
- Пустой старт; демонстрационный пример загружается по желанию.

`⌘N` — новая задача, `⇧⌘N` — новая цель. Меню по правой кнопке у цели позволяет изменить или удалить её. При удалении цели связанные задачи остаются без привязки.

## Apple Заметки и iPhone

В разделе «Apple Заметки» выберите список и нажмите «Поделиться», затем выберите Заметки в системном меню macOS. Если сервис не показывается, нажмите «Копировать» и вставьте список в заметку либо сохраните TXT и импортируйте его в Заметках через «Файл → Импортировать в Заметки».

Сохраните заметку в папке **iCloud**, чтобы открыть её на iPhone с тем же Apple Account и включёнными Заметками в iCloud. Файл на iPhone также можно отправить из приложения «Файлы» через «Поделиться → Заметки».

Это односторонний перенос текстового списка. Символы ☐ и ☑ не являются интерактивными чекбоксами Apple Заметок. Изменения в Заметках не возвращаются в приложение. При необходимости оформите импортированный текст как чеклист средствами Заметок.

Инструкции Apple: https://support.apple.com/en-gb/102223

## Данные

Сохраняются атомарно в `~/Library/Application Support/MyDashboard/dashboard.json` после каждого изменения. Предыдущая версия — `dashboard.previous.json` в той же папке. Перенос приложения не переносит данные: используйте JSON-копию в разделе «Данные».

Если исходный файл не читается, приложение не перезаписывает его и предлагает восстановление. При явном восстановлении повреждённый оригинал сохраняется отдельным файлом `dashboard.recovery-<UUID>.json`.

## Разработка

Нужны Apple Command Line Tools (`xcode-select --install`); полный Xcode не требуется.

```sh
./build.command
./test.command
```

Проект также описан в `Package.swift` и открывается в Xcode. Тесты проверяют расчёт прогресса, фильтры по датам, экспорт, сохранение, восстановление, удаление целей и ошибки записи.

Для проверки интерфейса с отдельным хранилищем:

```sh
open -n Build/MyDashboard.app --args --data-dir "$PWD/.qa-data"
```

Приложение не содержит WebView, Electron, сервер или веб-интерфейс. Незавершённая веб-версия была удалена. Метаданные `.openai/hosting.json` относятся к созданной ранее неопубликованной регистрации Sites; в сборке приложения они не используются.
